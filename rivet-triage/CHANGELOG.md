# Changelog

## 0.1.1 — Evidence-lineage hardening

- Added evidence lineage tracking and independent-vs-derivative corroboration discipline.
- Added anti-source-laundering evaluation coverage.

This methodology is frozen and is the initial public release, released as part
of the initial public Rivet family. Prior repository benchmark
validation was internal; benchmark artifacts are not packaged as independently
inspectable public evidence.

## 0.1.0 — Initial frozen methodology baseline

- Established the RivetTriage post-discovery reconciliation stage.
- Added source-finding validity checks before current canonical admission.
- Added conservative canonicalization, defect-identity deduplication, overlap classification, and complete source accounting.
- Added current-state verification, provenance reconciliation, and impact-based severity reconciliation.
- Added canonical `RT-*` findings and RivetClose handoff readiness states.
- Added report templates, focused evaluation cases, and release documentation.
