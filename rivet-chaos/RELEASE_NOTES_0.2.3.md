# RivetChaos v0.2.3

RivetChaos v0.2.3 is a bounded methodology refinement of the discovery-only adversarial behavioral review skill.

## What's notable in v0.2.3

- Bounded same-mechanism sibling discovery after sufficient root-mechanism evidence.
- Explicit sibling stop conditions and independent classification of each inspected sibling.
- Actor capability constraints for reachability and severity judgment.
- Clear separation between research scope and reportable scope.
- Cross-persona recurrence treated as corroboration, not proof.
- Explicit actor action → reachable mechanism → violated invariant → supported consequence reasoning.
- Focused declarative eval expansion for the refined behavior.

## Release status

**Pre-release.** No behavioral application benchmark has been run as part of this refinement.
