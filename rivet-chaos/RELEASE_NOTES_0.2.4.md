# RivetChaos v0.2.4

RivetChaos v0.2.4 adds a mandatory adversarial path closure gate before a scenario can be confirmed as a finding.

## What's notable in v0.2.4

- Literal actor, object, operation, state, invariant, and consequence accounting.
- Identity and cardinality conservation for multi-object and concurrent behavior.
- Explicit same-target versus distinct-target reasoning.
- Initial-state and state-transition validation.
- Counterfactual literal-execution self-challenge before confirmation.
- Focused declarative eval expansion for path closure.

## Release status

**Methodology frozen.** RivetChaos v0.2.4 is the initial public release,
released as part of the initial public Rivet family. A clean
post-refinement behavioral benchmark has not been run, and no such public
benchmark claim is made here.
