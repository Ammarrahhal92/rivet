Why Rivet?

Clear boundaries for difficult review work.

Separate stages. Discovery, canonical triage, and closure remain distinct responsibilities.

Keep uncertainty visible. Current evidence matters more than historical claims.

Stay portable. Each skill can be installed independently and used where it fits.

Quick start

Clone once. Install only what you need.

Copy a package directory into ~/.codex/skills/, then invoke the skill from your repository.

git clone https://github.com/Ammarrahhal92/rivet.git
cp -R rivet/rivet-chaos ~/.codex/skills/rivet-chaos
$rivet-chaos Audit this repository.
