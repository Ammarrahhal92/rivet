# Changelog

All notable changes to RivetPay are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project uses semantic versioning.

## [0.1.0] - 2026-09-13

Release-ready package for the intended initial public release; not yet publicly published.

### Added

- Provider-neutral payment and entitlement review methodology.
- Value Authority Graph and commercial grant-source classification.
- Payment-backed, trial, administrative, promotional, and migration/legacy grant analysis.
- Lifecycle, authority, entitlement, consumption, reconciliation, and provider-contract review.
- Product-policy and provider-contract evidence separation.
- Candidate discovery, generation/freeze integrity, canonical finding finalization, and deterministic reports.
- Renderer validation, tamper detection, methodology evals, and regression corpus.
- Discovery-only structured review artifacts.

### Validation

- Methodology unit and eval validation.
- Validation across materially different commercial models.
- Non-applicable payment-domain handling.

The package’s candidate duplicate handling is local review hygiene. Family-level
cross-source canonical identity and deduplication belong to RivetTriage.
